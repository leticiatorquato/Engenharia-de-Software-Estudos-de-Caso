# Locadora de Veículos

Projeto desenvolvido durante a disciplina de **Engenharia de Software**, com o objetivo de aplicar técnicas de análise, especificação e modelagem de sistemas a partir de um estudo de caso de uma locadora de veículos.

O trabalho contempla todo o processo de documentação de software, desde a compreensão do problema até a elaboração de diagramas, regras de negócio, requisitos e protótipos da solução proposta.

---

## Objetivo

Desenvolver a documentação técnica para um sistema de gerenciamento de uma locadora de veículos, buscando solucionar problemas relacionados ao cadastro de clientes e funcionários, controle da frota, locações, pagamentos e geração de relatórios.

---

## Conteúdo do Projeto

O documento contempla os seguintes artefatos:

- Introdução e fundamentação teórica;
- Estudo de caso;
- Levantamento das necessidades;
- Regras de negócio;
- Requisitos funcionais e não funcionais;
- Casos de uso;
- Diagramas UML;
- Arquitetura do sistema;
- Protótipos de média e alta fidelidade.

---
