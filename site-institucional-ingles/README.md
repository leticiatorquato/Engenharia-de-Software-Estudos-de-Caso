# Site institucional para curso de inglês

Projeto de **Engenharia de Requisitos** desenvolvido para a plataforma **T4 English**, um curso de inglês que buscava centralizar o gerenciamento acadêmico e fortalecer sua presença digital.

A documentação foi elaborada com base em reuniões de elicitação realizadas com o cliente, contemplando todas as etapas do processo de Engenharia de Requisitos, desde a compreensão do negócio até a especificação completa da solução.

---

## Objetivo

Analisar as necessidades do negócio e produzir a documentação técnica para uma plataforma web destinada ao gerenciamento do curso T4 English, oferecendo recursos para alunos e professores, como acesso a materiais, atividades, avaliações e acompanhamento acadêmico.

---

## Conteúdo do Projeto

A documentação contempla os seguintes artefatos:

- Plano de Ação (5W2H);
- Documento de Análise de Negócio;
- Árvore de Problemas;
- Árvore de Objetivos;
- Lista de Funcionalidades;
- Elicitação de Requisitos;
- Especificação de Casos de Uso;
- Requisitos Funcionais;
- Requisitos de Qualidade;
- Requisitos de Dados;
- Regras de Negócio;
- Restrições do Sistema;
- Protótipos de Alta Fidelidade.
