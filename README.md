# Projetos de Engenharia de Software

Repositório destinado à documentação de projetos desenvolvidos durante a graduação em Análise e Desenvolvimento de Sistemas.

Os projetos contemplam etapas fundamentais da Engenharia de Software, incluindo levantamento e análise de requisitos, modelagem, definição de regras de negócio, diagramas UML, prototipação e documentação técnica.

---

## Projetos

### Locadora de Veículos

Estudo de caso voltado ao desenvolvimento de um sistema para gerenciamento de uma locadora de veículos.

Principais artefatos desenvolvidos:

- Levantamento do problema;
- Regras de negócio;
- Requisitos funcionais e não funcionais;
- Casos de uso;
- Diagramas UML;
- Arquitetura do sistema;
- Protótipos de média e alta fidelidade.

**Tecnologias e ferramentas**

- UML
- Figma
- Miro
- Engenharia de Requisitos

---

### T4 English

Projeto de Engenharia de Requisitos desenvolvido para um curso de inglês, com foco na análise do negócio e definição dos requisitos de uma plataforma web.

Principais artefatos desenvolvidos:

- Plano 5W2H;
- Documento de Análise de Negócio;
- Elicitação de Requisitos;
- Especificação de Requisitos;
- Casos de Uso;
- Protótipos.

**Tecnologias e ferramentas**

- BPMN
- Figma
- Miro
- Engenharia de Requisitos

---

## Objetivo

Este repositório reúne estudos de caso desenvolvidos durante a graduação, demonstrando a aplicação prática de técnicas de Engenharia de Software e Engenharia de Requisitos na análise e documentação de sistemas.
